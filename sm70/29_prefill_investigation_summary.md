# Q36 TP1 prefill 调查最终报告（SM70 / V100 / nvfp4）

> 结论先行：**在"不改变模型与量化格式、不引入近似"的前提下，Q36 TP1 的 prefill
> 生产内核（41.2 TF/s = 33.5% 峰值）就是这套算法栈在 V100 上的实用上限**。
> 全部候选路径均经实测关闭，其中两条被做成内核并通过服务三明治门复测。
> 详细时间线见 `sm70/03_history.md` (55)–(68)。

## 1. 结论数字

| 项 | 实测 | 说明 |
|---|---|---|
| dense GEMM（占 prefill 55.6%） | 同形状 cuBLAS 的 **95–96%** = 峰值 ~70% | cuBLAS 自身只到 72–76% |
| MoE prefill（占 23.4% @65K 尺子） | **41.2 TF/s = 33.5% 峰值** | chunk 8K→32K 平坦 41.1–41.5 ⇒ 非形状问题 |
| attention/softmax（13.7%） | 稀疏 QSA + 已调优 | 未见 >3% 空间 |
| GDN（9.6%） | CUDA 内核唯一形态 | Triton 回退启动失败 |

**合计理论剩余空间 ≈8%，全部需要 cuBLAS 级内核重写**；已实现的两版（wmma / 手写 mma）
隔离最好 51.3 TF/s，但集成后服务实测 **−1.5%**。

## 2. 已关闭的路径（全部有命令/数据）

| # | 路径 | 结果 |
|---|---|---|
| 1 | chunk 8192→16384 | GPU0 OOM（2.6M KV 池下 8192 是最大可行） |
| 2 | GDN Triton 回退 | engine init 失败（KV 尺寸） |
| 3 | 启动器旋钮（WIDE/WARPS/NS/两遍） | ≤3.7% |
| 4 | 占用率强压（launch_bounds 2 CTA/SM） | **9.2× 劣化**（160 寄存器是刚需） |
| 5 | wmma weight-major 原型 | 28.1→33.5 TF/s 封顶 < 41.2 |
| 6 | 形状（chunk 8K/16K/32K） | 41.1/41.4/41.5 平坦 |
| 7 | 预解量化 B（Fp16B） | 24.7 vs 34.5 **更慢**（字节翻倍） |
| 8 | route block 32 行 | 内核只支持 8/16 |
| 9 | 手写 mma 大 tile（fp16 权重） | 位等，隔离 44–48 TF/s（1.07–1.16×，抖动 ±8%） |
| 10 | 手写 mma + nvfp4 共享反量化面板 | 位等（vs 生产 dense gemm 0.0625），隔离 **51.3 TF/s（1.25×）** |
| 11 | 上述内核集成 + m 门控 + 回环遍历 | **服务门 65K prefill −1.5%/−0.8%（两次独立门）** |

## 3. 为什么隔离 1.34× 不转移（机制）

1. **间接 gather**：真实路由下每个专家的 A 行来自 `sorted_token_ids` 的散列（离线基准用连续行）；
2. **MoE 只占 prefill 23.4%**：即使 MoE 快 34%，全量也只有 −9% 的上限，而实测只覆盖 w13（55%）→ 理论 −2.6%；
3. **每 n-tile 重复读 A**：grid 有 8 个 n-tile，A 被读 8 次（L2 可缓解，但 off-peak）；
4. 生产内核的 16 行 route block 让 B 完全落在 L2，而 weight-major 的 256 行块反而让 A 的 gather 暴露。

## 4. fuse_act 语义（已判定）

真实服务 `VLLM_SM70_MOE_FUSE_ACT=0` vs `=1`，同一 greedy 请求输出 **逐字相同（909 字符）**
⇒ 生产融合路径与关闭融合等价，语义正确。先前合成探针的"gate=0/up=1 非零"是**合成调用假象**
（`fuse_act=True` 的 op 入口未走融合模板），已澄清。

## 5. 若未来要重启这条线

- 先解决 **gather**（把 A 行按专家聚成连续块，或预取）；
- 再考虑把 MoE **占 prefill 比例**降低（例如与 attention/QSA 的融合），否则上限仍是 −9% × 转化率；
- 任何变体必须过**三明治门**（同场基线前后夹 + 65K/250K + canary/recall/secret + 0 Xid），
  隔离数据不作为判据（本报告的核心教训）。
